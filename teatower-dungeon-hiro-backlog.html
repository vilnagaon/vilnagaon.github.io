Teatower Dungeon · living systems backlog (not an eng sprint list). Goal: turn knowledge checks into interesting decisions without bloating a brand tower into Civ.

Project: Teatower Dungeon Author: Hiro Updated: 2026-07-31 Stack: SpriteKit · SwiftUI · 5 floors
Sid Meier: “A game is a series of interesting decisions.” Right now Teatower has a charming series of checks. This backlog is how we fix that.

2 · P0 — Make existing systems interesting

Highest ROI. Holes in systems already in the build.

ID System Problem Design work
D-01 P0 Quiz integrity Correct answer is always choices[0] in data. Quizzes are pass/fail, not tradeoffs. Risk/reward quizzes: wager leaves, difficulty tiers, confident vs safe answer. Content policy on answer order.
D-02 P0 Battle decision density Linear ATT/DEF/LUCK. Defend + Earl Shield = turtle. Few interesting choices after floor 1. Tea-type matchups or stances. Cap permanent stack or convert quiz power into spendable infusions.
D-03 P0 Economy (leaves) Sources: props, battles, quiz. Sink: one shop on floor 0. Mid-tower leaves idle. Floor shops (NPC-themed) or ascent rituals: spend before door for floor buffs. Always one leaf short.
D-04 P0 Failure & recovery HP = 0 rules unclear / soft. Risk is fake if death costs nothing. Spec death loop (lose half leaves, keep items; or one Nicolas bail-out per run).
D-05 P0 Gate clarity Door vs quiz vs 2 battles — what is required? Hidden rules fail Theme Hospital standard. One-sentence rule players can recite, surfaced in UI.

3 · P1 — Floor fantasy (tea + staff + tower)

ID System Intent Deliverable
D-10 P1 Floor identity L3/L4 quizzes were TBD; rooms (kitchen, stock) aren’t gameplay. Per-floor pack: quiz topic, unique prop behavior, unique enemy or shop item.
D-11 P1 NPC dialog (light) Staff feel like quiz kiosks. 2–3 branch dialogs each (flavor, tip, optional challenge). No full VN.
D-12 P1 Monster roster 2 sprites reused; boss = +stats. 1 unique foe/floor + Ancestral Teapot phase rule (steam = DEF up → item timing).
D-13 P1 Item design space 3 flat items: heal / shield / flee. +1 mid exclusive, +1 late exclusive for build identity without jobs.
D-14 P1 Endgame stance Voucher is great brand payoff; zero mastery after. Optional Expert Tower / NG+ or declare 45-min campaign and stop padding.

5 · Economy snapshot

As designed today

SOURCES SINKS props (1–2 leaves) → shop (3/4/5 leaves) — lobby only battle rewards → ? (nothing mid-tower) quiz permanent stats → (not a sink — power inflation)

Target (P0 · D-03)

Every floor: small income → optional spend (shop / door ritual / brew) Permanent stats: capped or split into temporary infusions Feel: player always slightly short of “perfect” kit for next boss

6 · Balancing debt

Risk Symptom Lever
Stat inflation Quiz + battle rewards stack ATT forever Soft cap, or rewards become items not +1 ATT
Turtle meta Defend + Earl Shield Shield once/battle; defend reduces, doesn’t zero
Flee cheese Smoke Leaf + high luck 1 guaranteed flee / floor; boss-immune
Quiz content Correct index always 0 Pipeline rule + harder distractors
Optional combat Skip fights if quiz alone opens door Force 1 fight or fights = only power source
